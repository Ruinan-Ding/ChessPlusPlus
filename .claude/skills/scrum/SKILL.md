# Scrum delivery

Use `$ARGUMENTS` or the active request. Apply the loaded [core](../../../AGENTS.md)
and read the [workflow](../../../SCRUM_WORKFLOW.md) once as lead. Inspect only the
[backlog's current-work pointer](../../../SCRUM_BACKLOG.md#current-work): resume
its contract only if it matches the request. Otherwise create/update the matching
contract; completed work is not every new task's context.

For informal/vibe requests use [intake](references/intake.md). Keep one contract
linking intent → requirements → BDD examples → TDD checks → source evidence.
Use [config-sync](../config-sync/SKILL.md) for config-shape changes. Read affected
references/source only; resume from the contract's short continuation state.

Default to the lead; activate relevant specialists within runtime policy.
Workers use bounded packets, not this intake again. Preserve dirty work, one
writer per file, mandatory checks and existing publication/service authorization.
